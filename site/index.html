Develata APT Repository

Debian and Ubuntu packages of software published by Develata, built from each project's GitHub releases. Source: Develata/apt-repo.

Set up

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL @BASE_URL@keys/develata-archive-keyring.gpg | sudo tee /etc/apt/keyrings/develata-archive-keyring.gpg > /dev/null
curl -fsSL @BASE_URL@develata.sources | sudo tee /etc/apt/sources.list.d/develata.sources > /dev/null
sudo apt update

Signing key fingerprint: @FINGERPRINT@

    @PACKAGES@

Install with sudo apt install <package>; later releases arrive through sudo apt upgrade.
